## 🚀 Quick Start Guide

### Step 1: Clone & Setup
```bash
git clone https://github.com/Aditya891752/powerbi-projects.git
cd powerbi-projects
```

### Step 2: Choose Your Project

#### **Project 1: Personal Habit Dashboard (Easier, Faster)**
```bash

python 01_Data_Generation.py  # Generates personal_habit_tracking_6months.csv
```

**Then:**
1. Open Power BI Desktop
2. Get Data → CSV → Load `personal_habit_tracking_6months.csv`

## ⚡ Pro Tips from a 20-Year SQL Veteran

### Data Integrity:
- ✅ Always validate your Python-generated data before import
- ✅ Check for missing values, duplicates, outliers
- ✅ Use Power BI's data profiler (View → Data Preview)

### DAX Best Practices:
- ✅ Use variables (VAR) to break complex measures into steps
- ✅ Add comments explaining the business logic
- ✅ Test measures with simple row contexts first
- ✅ Use CALCULATE to override filter context explicitly

### Performance Optimization:
- ✅ Avoid complex DAX in calculated columns (use measures instead)
- ✅ Create aggregated tables for large datasets
- ✅ Use SUMMARIZECOLUMNS for efficient multi-level grouping

### Design Excellence:
- ✅ Less is more (3-4 visuals per page is ideal)
- ✅ Use consistent color palette across all pages
- ✅ White space matters (don't crowd visuals)
- ✅ Make drill-throughs intuitive (clear navigation)

### Documentation:
- ✅ Document your DAX measures (especially complex ones)
- ✅ Add tooltips explaining KPIs
- ✅ Create a quick-reference guide for your dashboard
- ✅ Screenshot key pages for your portfolio
